# 使用指南

下文的 ⌘/Ctrl 表示 macOS 使用 ⌘，Windows / Linux 使用 Ctrl。从源码运行见 [README](../README.md#从源码运行)。

## 文件比较

1. 点击“打开”或按 ⌘/Ctrl O，选择两个文件；只选一个时，继续选择右侧文件。
2. 按 F7 / Shift F7 跳到下一处 / 上一处差异，也可点击或拖动右侧概览条。
3. 直接编辑右侧；编辑左侧前，点击“左侧编辑”。
4. 点击“采用左侧”将当前差异块复制到右侧；采用右侧前需开启左侧编辑。“比较”菜单还可组合两侧内容。
5. 按 ⌘/Ctrl S 保存当前侧，或按 ⌘/Ctrl Shift S 另存为。

其他操作：

- **新建文本比较**：选择“文件 → 新建文本比较”或按 ⌘/Ctrl N，粘贴或输入文本。
- **交换左右**：点击“交换左右”。三方合并或指定输出位置时不可交换。
- **拖放文件**：拖入两个文件开始新比较；拖入一个文件，替换落点所在侧。三方合并或指定输出位置时不支持单侧替换。
- **重新加载**：文件在外部修改后会显示提示，点击“重新加载”读取最新内容；有未保存修改时按提示处理。
- **查找 / 替换 / 跳转行**：按 ⌘/Ctrl F、⌘/Ctrl Alt F、⌘/Ctrl G。

## 显示与比较选项

| 需要的操作 | 入口 |
| --- | --- |
| 自动换行、显示空白字符、概览条、行详情、工具栏文字 | 视图菜单 |
| 只看差异及附近行 | 视图 → 只看差异；上下文行数在“设置 → 比较”调整 |
| 展开省略内容 | 点击省略提示带或“显示全文” |
| 忽略行首 / 行尾空白、大小写或换行差异 | 比较 / 合并菜单 |
| 切换单词差异、移动代码识别 | 比较 / 合并菜单 |
| 跳到移动代码的另一侧 | 在底部行详情点击“移动代码” |
| 调整语言高亮、Tab 显示宽度 | 点击文件底部对应选项 |

忽略选项只影响显示，不改写文件，也不改变三方合并判断。

## 三方合并

1. 选择“文件 → 打开三方合并”。
2. 在面板中填写或浏览选择共同祖先、左侧输入、右侧输入和结果位置；可从“最近使用的合并”回填路径。
3. 检查路径后点击“打开合并”，按 F8 / Shift F8 跳转冲突。
4. 采用任一侧，或在“合并”菜单组合双方、保留祖先；也可编辑结果，再标记为已手工解决。
5. 确认全部冲突后，按 ⌘/Ctrl S 保存。

输入栏只读。查看祖先用“合并 → 查看共同祖先”；修改输入编码后需重新处理合并结果。未确认的冲突会阻止保存。

Git 合并时按界面上的来源名称选择：

| Git 操作 | 左侧 | 右侧 |
| --- | --- | --- |
| merge | 当前分支 | 合入版本 |
| rebase | 目标历史 | 本次提交 |

rebase 时不要把左右侧直接理解为“我的 / 别人的代码”。若来源未识别，可点击“识别 Git 来源”，按提示授权仓库目录后重试。

## 编码与保存

- **更换读取编码**：点击输入文件底部的编码，选择实际编码；重新读取会丢弃该侧未保存修改，需确认。
- **转换保存编码 / 换行**：使用“另存为”，选择编码和 LF / CRLF / CR。合并结果与未命名文本也可直接在底部设置。
- **启用备份**：在“设置 → 文件与权限”开启 `.bak` 备份。
- **磁盘文件已改变**：按提示取消、另存为或明确覆盖磁盘版本。
- **macOS 提示授权**：选择文件所在目录或其父目录；撤销授权用“设置 → 文件与权限 → 撤销已授权文件与目录”。

自动读取支持 UTF-8 和带 BOM 的 UTF-16。旧编码或无 BOM 的 UTF-16 请手动选择；GB18030、EUC-KR 请先转为 UTF-8。无法无损转换时，改用能表示完整文本的编码。

单文件最大 32 MiB；超长行显示可能截断，源文件内容不受影响。

## Git 暂存

需要安装 Git，且文件已被 Git 跟踪。

**按选中代码暂存：**

1. 保存当前文件。
2. 选中修改行，右键点击“暂存所选代码块”；不选文本时使用右键所在行。
3. 在终端用 `git diff --cached` 检查结果，再执行 `git commit`。

选择一行也会暂存整个差异块。

**预览与取消暂存：**

1. 选择“工具 → Git 暂存预览 / 取消暂存”。
2. 切换“未暂存”或“已暂存”，勾选区块。
3. 点击“暂存所选块”或“取消暂存所选块”。文件或索引变化后，先刷新再选择。

执行期间可点击“取消操作”，超时会自动停止；取消后先刷新确认索引状态。

超长区块的预览会截断，操作仍作用于完整区块。权限不足时，按提示授权仓库目录；worktree 可能需要授权共同父目录。

## 命令行与 Git

```sh
./tool/fmerge LEFT RIGHT
./tool/fmerge --base BASE --local LOCAL --remote REMOTE --output MERGED
./tool/fmerge --read-only LEFT RIGHT
./tool/fmerge --help
```

| 参数 | 用法 |
| --- | --- |
| `--output PATH` | 指定保存目标；双栏模式用于右侧 |
| `--auto-close` | 保存成功后关闭窗口 |
| `--wait` | 等待窗口关闭，默认已启用 |
| `--read-only` | 只读预览 |

Windows 使用 `fmerge.exe` 或 `tool/fmerge.ps1`。支持 `/base:... /mine:... /theirs:... /merged:...` 参数形式。

**配置 Git 外部工具：**打开“设置 → Git 集成”，复制配置并在终端执行；或替换以下示例中的程序路径：

```sh
git config --global diff.tool fmerge
git config --global difftool.fmerge.cmd '"/absolute/path/to/fmerge/tool/fmerge" "$LOCAL" "$REMOTE"'
git config --global merge.tool fmerge
git config --global mergetool.fmerge.cmd '"/absolute/path/to/fmerge/tool/fmerge" --base "$BASE" --local "$LOCAL" --remote "$REMOTE" --output "$MERGED"'
git config --global mergetool.fmerge.trustExitCode true
```

macOS 安装后也可使用 `/Applications/fmerge.app/Contents/MacOS/fmerge`。需指定 Git 程序时，设置环境变量 `FMERGE_GIT`。

退出码：`0` 为比较正常结束或合并已完成并保存，`1` 为合并取消 / 未完成，`64` 为参数错误。

## 崩溃恢复

1. 在“设置 → 文件与权限”开启“崩溃恢复”。
2. 异常退出后，选择“文件 → 恢复未保存会话”，点击记录恢复，或点击删除按钮清理。
3. 检查恢复内容并保存。

恢复默认关闭；开启后会在本机保存正文和冲突状态，不包含撤销历史。连续输入时最多每 5 秒触发一次保存。正常保存或确认离开会清理当前记录；其他运行窗口的记录不会出现在恢复列表中。

## 外观与快捷键

- **主题 / 字体**：在“设置 → 编辑器与外观”调整。
- **自定义主题**：选择“自定义”，修改颜色后保存；可编辑、另存、删除，或导入 / 导出 `.fmerge-theme.json`。不支持直接导入 VS Code / Zed 主题。
- **修改键位**：在“设置 → 快捷键”点击键位并录制新组合；可清除绑定或恢复默认。

| 操作 | 默认快捷键 |
| --- | --- |
| 新建文本比较 | ⌘/Ctrl N |
| 打开 / 保存 / 另存为 | ⌘/Ctrl O / ⌘/Ctrl S / ⌘/Ctrl Shift S |
| 查找 / 替换 / 跳转行 | ⌘/Ctrl F / ⌘/Ctrl Alt F / ⌘/Ctrl G |
| 上一处 / 下一处差异 | Shift F7 / F7 |
| 上一处 / 下一处冲突 | Shift F8 / F8 |
| 上一处 / 下一处行内差异 | Shift Alt F7 / Alt F7 |
| 采用左侧 / 采用右侧 | Alt → / Alt ← |
| 左侧编辑 / 暂存所选块 | ⌘/Ctrl Alt E / ⌘/Ctrl Alt S |
| 设置 | ⌘/Ctrl , |

Mac 功能键可能需要配合 Fn。
