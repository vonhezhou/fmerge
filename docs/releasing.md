# 发布验收清单

当前版本为 0.1.0 预览版。源码公开不代表各桌面平台均已验收；本清单中的未勾选项不能根据历史记录自动视为完成。

## 源码公开前

- [x] 项目根目录提供 MIT 许可证，第三方声明与编辑器上游许可保留。
- [x] CI 固定 Flutter 3.47.9，锁文件使用官方依赖源。
- [x] README 提供运行方式、使用边界和贡献入口。
- [x] 在不含本地缓存和生成文件的干净源码副本中完成官方源依赖安装、203 个测试、静态检查与 macOS Release 构建（2026-11-05）。
- [ ] 检查拟公开的 Git 历史、作者信息和资源，确认均可公开。常见令牌模式扫描不能替代此项确认。

## 每次二进制发布

- [ ] 更新 `pubspec.yaml` 的版本，并同步 `lib/main.dart` 中命令行版本和应用“关于”版本文案。
- [ ] 检查工作区状态并运行 `python3 tool/check.py --build`。
- [ ] macOS 运行 `python3 tool/check.py --native --build`；确保最终产物来自正常产品入口，而非性能测试入口。
- [ ] 运行 `python3 tool/package.py`，核验压缩包内容与 `dist/SHA256SUMS.txt`。
- [ ] 发布说明分别记录实际通过的平台、架构、签名及已知问题。

## 仍需人工验证

- [ ] macOS 系统选择器选择外部受保护目录后可保存，书签重启后可恢复，撤销授权后行为正确。
- [ ] 真实中文输入法组合输入、候选确认、撤销与保存 / 关闭保护。
- [ ] Windows：打开、保存覆盖、备份、Git 集成、退出码与路径含空格 / 非 ASCII 字符。
- [ ] Linux：打开、保存覆盖、备份、Git 集成、退出码与系统文件选择器。
- [ ] 目标硬件上的冷启动、大文件滚动 / 换行、三方合并编辑及内存表现。
- [ ] 键盘访问与无障碍基础流程。
- [ ] 对外分发 macOS 包时评估 Developer ID 签名与公证，并验证首次安装体验。

性能优化与 `workbench.dart` 职责拆分可以后续独立推进，应先以测量确定收益，不作为本轮发布前重构。
